# موقع بيع المسمنة عبر انستغرام — دليل الإعداد

هذا الموقع يتكون من صفحتين:
- **index.html** — الصفحة التي يراها الزبون (المنتج + العروض + استمارة الطلب)
- **admin.html** — لوحة تحكم خاصة بك فقط، تظهر فيها كل الطلبات مع إمكانية تأكيدها أو إلغائها

بما أن GitHub لا يخزن بيانات (هو فقط يعرض ملفات)، تحتاج قاعدة بيانات مجانية بسيطة اسمها **Firebase** من Google لتخزين الطلبات وربطها بلوحة التحكم. الإعداد يستغرق حوالي 10 دقائق ولا يحتاج خبرة برمجية.

---

## الخطوة 1: إنشاء مشروع Firebase

1. اذهب إلى: https://console.firebase.google.com
2. سجّل الدخول بحساب Google، ثم اضغط **Add project / إضافة مشروع**
3. اختر اسماً (مثلاً: `mosamana-shop`) واتبع الخطوات (يمكنك تعطيل Google Analytics، غير ضروري)

## الخطوة 2: إضافة تطبيق ويب للحصول على مفاتيح الربط

1. داخل مشروعك، اضغط على أيقونة **</>** (Web app)
2. أعطه اسماً (مثلاً `site`) واضغط **Register app**
3. ستظهر لك قيم شبيهة بهذا:
```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "mosamana-shop.firebaseapp.com",
  projectId: "mosamana-shop",
  storageBucket: "mosamana-shop.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};
```
4. انسخ هذه القيم والصقها في ملف **firebase-config.js** بدل الأماكن المكتوب فيها "ضع...هنا"

## الخطوة 3: تفعيل قاعدة البيانات (Firestore)

1. من القائمة الجانبية: **Build → Firestore Database**
2. اضغط **Create database**، اختر **Start in production mode**، ثم اختر أي موقع خادم قريب (مثلاً `eur3`)
3. بعد الإنشاء، اذهب لتبويب **Rules** والصق هذا بدل المحتوى الموجود:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /orders/{orderId} {
      allow create: if true;
      allow read, update: if request.auth != null;
      allow delete: if false;
    }
  }
}
```

هذا يسمح لأي زبون بإرسال طلب، لكن لا يستطيع أحد قراءة الطلبات أو تعديلها إلا أنت (بعد تسجيل الدخول). اضغط **Publish**.

## الخطوة 4: تفعيل تسجيل الدخول للوحة التحكم

1. من القائمة الجانبية: **Build → Authentication**
2. اضغط **Get started**، ثم فعّل طريقة **Email/Password**
3. اذهب لتبويب **Users** واضغط **Add user**، أدخل بريدك الإلكتروني وكلمة مرور خاصة بك (هذه ستكون بيانات دخولك للوحة التحكم في admin.html)

---

## الخطوة 5: إضافة صورة المنتج

ضع صورة منتجك في نفس المجلد باسم **product.jpg** (بجانب ملف index.html).

## الخطوة 6: رفع الموقع على GitHub

1. أنشئ مستودع (Repository) جديد على GitHub
2. ارفع جميع ملفات هذا المجلد إليه
3. من إعدادات المستودع: **Settings → Pages** → اختر الفرع `main` والمجلد `/root` → احفظ
4. بعد دقيقة أو دقيقتين ستحصل على رابط مثل:
`https://username.github.io/repo-name/`

هذا هو رابط صفحة الزبون. رابط لوحتك الخاصة هو نفس الرابط + `admin.html`، مثال:
`https://username.github.io/repo-name/admin.html`
(هذا الرابط لن يجده أحد ما لم تُعطه له، ولن يقدر أحد على رؤية الطلبات دون بيانات دخولك)

## الخطوة 7: ربط الرابط بمنشور انستغرام

انستغرام لا يسمح بوضع زر "Acheter" داخل المنشور نفسه إلا عبر:
- **رابط في السيرة الذاتية (Bio)** + كتابة "اضغط على الرابط في البايو" في المنشور، أو
- **زر رابط في الاستوري (Link Sticker)**، أو
- تفعيل **Instagram Shopping** الرسمي (يتطلب مراجعة من فيسبوك ومنتجات مطابقة لسياساتهم، وغالباً غير مناسب لمكملات التسمين)

الطريقة الأسهل والأكثر استخداماً: ضع الرابط في البايو، واكتب في كل منشور "🔗 الرابط في البايو للطلب".

---

## كيف تستعمل لوحة التحكم يومياً

1. افتح رابط `admin.html` وسجّل الدخول ببريدك وكلمة مرورك
2. ستظهر لك كل الطلبات فور وصولها (تحديث تلقائي بدون إعادة تحميل الصفحة)
3. اتصل بالزبون لتأكيد الطلب، ثم اضغط زر **تأكيد** أو **إلغاء** حسب الرد

## ملاحظات مهمة

- الموقع مجاني بالكامل ضمن الحدود المجانية لـ Firebase (تكفي بسهولة لمئات الطلبات يومياً)
- لا تشارك رابط `admin.html` مع أحد، ولا تشارك بيانات الدخول
- يمكنك تغيير الألوان والنصوص من ملف `style.css` و `index.html` بحرية
